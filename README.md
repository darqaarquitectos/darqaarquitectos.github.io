# DARQA V1 INTEGRADO — ETAPA 12

## Portafolio Integral — ajuste visual de Metodología

Esta etapa parte de ETAPA 11 y modifica únicamente la presentación visual de los iconos de la sección MÉTODO/METODOLOGÍA.

### Cambios
- Los emojis/iconos de metodología pasan a tener mayor presencia visual.
- Cada icono se presenta dentro de un círculo oscuro de 66 px, inspirado en la jerarquía visual del portafolio PDF de DARQA.
- Se mejora la separación entre número, icono, título y descripción.
- Se reduce el espacio vacío de las tarjetas sin alterar la estructura de 6 bloques existente.
- Se mantiene el enfoque editorial y responsive.

### No se modificó
- Contenido de las 6 etapas.
- Navegación del Portafolio Integral.
- Páginas independientes del Portafolio Integral.
- Página principal y páginas principales de DARQA.
- Formulario de contacto y su lógica de WhatsApp.
- Visor de proyectos.
- Datos e imágenes de proyectos.
